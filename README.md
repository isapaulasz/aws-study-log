## 📚 Plataformas de estudo

### 🎓 AWS Educate

O **AWS Educate** é a porta de entrada da AWS para quem está começando, com conteúdos gratuitos para aprender os conceitos básicos de computação em nuvem e conhecer carreiras na área.

- Introdução acessível a cloud computing
- Trilhas de aprendizado e badges de conclusão
- Ótimo para construir a base antes de avançar

📂 **Na pasta:** anotações dos cursos concluídos e resumos dos conceitos fundamentais.

### 🛠️ AWS Skill Builder

O **AWS Skill Builder** é a plataforma oficial de treinamento da AWS, com uma grande biblioteca de cursos, laboratórios e materiais de preparação para as certificações.

- Cursos oficiais, de iniciante a avançado
- Laboratórios para praticar em ambiente real
- Preparação para certificações, como a Cloud Practitioner

📂 **Na pasta:** anotações por curso, resumos de módulos e registros dos laboratórios realizados.

### 🎮 AWS Cloud Quest

O **AWS Cloud Quest** transforma o aprendizado de cloud em um jogo: você cumpre missões dentro de uma cidade virtual e coloca a mão na massa com serviços reais da AWS.

- Aprendizado gamificado, em formato de missões
- Prática guiada com serviços da AWS
- Trilhas por função, como Cloud Practitioner e Solutions Architect

📂 **Na pasta:** registros das missões concluídas, o que aprendi em cada desafio e os serviços utilizados.
